Backup wiederherstellen

Spielt eine zuvor heruntergeladene .json-Datei auf diesem Gerät zurück. Bestehende lokale Daten werden überschrieben.

Lokal = nur dieses Gerät. Cloud = alle Geräte (PC + iPad + Handy) sehen die Daten sofort. Bestehende Cloud-Daten desselben Kunden werden überschrieben — wähle das Gerät mit dem aktuellsten Stand.
